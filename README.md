# 자재센터 출입 신청 앱 (Entry-Pass) — MVP

자재센터 출입 차량 기사가 **출입 전 안전수칙을 확인하고 사전 출입 승인을 신청**하면,
자재센터 직원이 이를 **확인 후 승인/반려**하는 모바일 웹앱입니다.
(아파트 방문차량 사전승인과 동일한 개념 — 경비실 구두 요청 대신 사전 승인)

## 핵심 기능

- **차량 유형 선택** → 유형별로 아래 내용이 자동으로 달라집니다.
  - **안전수칙 안내 + 동의** (동의해야 다음 단계 진행)
  - **차량 동선 안내** (센터 내 이동 경로)
  - **필요 서류 업로드** (유형별 필수/선택 서류)
- **출입 신청 제출** (기사명·연락처·차량번호·방문일시·목적)
- **직원 승인/반려** — 신규 신청이 직원 화면에 5초 폴링으로 실시간 반영
- **승인번호 발급 및 상태 조회** (기사 화면에서 승인/대기/반려 확인)
- **모바일 우선 UI + PWA** (홈 화면에 추가하면 앱처럼 사용, 다크모드 지원)

기본 제공 차량 유형(샘플): 대형 화물차 / 중·소형 화물차 / 탱크로리·위험물 /
지게차·특수장비 / 방문 승용차

## 실행 방법

```bash
npm install
npm start          # http://localhost:3000
```

- 운전기사 화면: 첫 화면에서 **운전기사** 선택
- 직원 화면: 첫 화면에서 **자재센터 직원** 선택
- 휴대폰에서 접속하려면 같은 네트워크에서 `http://<PC-IP>:3000` 로 접속하거나,
  배포 후 URL/QR로 공유하면 됩니다.

## 실제 내용으로 교체하기

차량 유형·안전수칙·동선·서류 목록은 모두 아래 한 파일에 모여 있습니다.

- **`data/vehicleTypes.js`** — 유형 추가/수정 시 이 배열만 편집

예: 유형 하나를 추가하려면 배열에 객체 하나를 더하면 되고,
안전수칙 문구를 바꾸려면 해당 유형의 `safetyRules` 배열만 수정하면 됩니다.

## 구조

```
server.js              백엔드 (Express) — 신청 생성/조회/승인/반려 API
data/vehicleTypes.js   차량 유형별 안전수칙·동선·서류 설정
data/db.json           신청 데이터 저장 (자동 생성, git 제외)
uploads/               업로드된 서류 저장 (자동 생성, git 제외)
public/                모바일 웹 프런트엔드 (빌드 불필요)
  index.html
  css/styles.css
  js/app.js
```

## API 요약

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/vehicle-types` | 차량 유형별 설정 조회 |
| POST | `/api/requests` | 출입 신청 생성 (multipart, 서류 첨부) |
| GET | `/api/requests?status=pending` | 신청 목록 (직원) |
| GET | `/api/requests/:id` | 신청 단건 상태 조회 (기사) |
| POST | `/api/requests/:id/approve` | 승인 |
| POST | `/api/requests/:id/reject` | 반려 (사유 포함) |
